# Remote Team Culture and Engagement Discord Bot

A Discord bot for remote-first companies and distributed teams building culture at scale. Runs weekly team trivia games, facilitates virtual coffee roulette pairings, celebrates birthdays and work anniversaries automatically, conducts anonymous pulse surveys, tracks team mood trends, and posts weekly shoutout boards recognizing peer contributions. Fully configurable with HR system integrations.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
